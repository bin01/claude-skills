# claude-skills

Personal Claude skills. Each folder is one skill with a `SKILL.md`.

| Skill | What it does |
|---|---|
| [raise-the-bar](raise-the-bar/SKILL.md) | Rewrites a task prompt to be more ambitious along altitude, depth, or range before running it. Based on Felix Rieseberg's [How to be more ambitious](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/). |

## Install in Claude Code

```sh
git clone git@github.com:bin01/claude-skills.git ~/code/claude-skills
ln -s ~/code/claude-skills/raise-the-bar ~/.claude/skills/raise-the-bar
```
